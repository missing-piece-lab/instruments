## How we work
- think → plan → build → verify; the smallest change that finishes the task
- state is observed, never written by hand: if a probe can check it, documentation does not assert it
- a merge is its own step, never chained into a commit or a push
- two holds on a branch and the next call is the human's, never a third round
- celebrate the wins; name what went wrong without ceremony
